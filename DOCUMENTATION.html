2. Multi-Agent Coordinated Intelligence Architecture

The core of EventEase AI is an autonomous, multi-agent orchestration architecture coordinated by a central Orchestrator Agent:

  • Central Orchestrator Agent (orchestrator.py): Ingests natural language prompts in English, Gujarati, or Hindi. Extracts structured parameters, delegates execution to domain-specific sub-agents, reconciles cross-agent trade-offs, and powers the What-If simulation engine without overwriting saved plans without user consent.
  • Budget Agent (budget_agent.py): Implements deterministic mathematical algorithms in Python (avoiding LLM arithmetic errors). Guarantees 100% budget accuracy, locks an auto-calculated 10% Contingency Reserve, computes per-guest metrics, and recommends concrete cost-reduction substitutions.
  • Venue & Space Agent (venue_agent.py): Calculates precise carpet area formulas (Guests × 15 sq ft + 1000 sq ft for Mandap/Stage), computes parking spot ratios, and assesses indoor/outdoor weather vulnerability.
  • Theme & Decor Studio Agent (theme_agent.py): Synthesizes culturally authentic Indian aesthetics (Bandhani, Marigold, Kesariya, Patola Green), generates 5-color HEX palettes, mandap architectures, and 8K photorealistic image-generation prompts.
  • Catering Agent (catering_agent.py): Calculates a +10% headcount buffer (e.g., 300 guests → 330 buffered plates), provisions separate Jain food preparation counters, provides cost-per-plate estimates, and establishes surplus food recovery NGO protocols.
  • Smart Timeline Agent (timeline_agent.py): Computes backwards milestone schedules from the event target date (T-120 days down to T-0 execution) with priority classifications and dependency propagation.
  • Risk Management Agent (risk_agent.py): Formulates probability and severity matrices for weather disruptions, caterer delays, budget overruns, and power failures, generating actionable contingency playbooks.

4. API Efficiency & Caching Strategies

To eliminate redundant network roundtrips and ensure instantaneous page navigation across the SaaS dashboard, a client-side in-memory caching engine was engineered:

Client-Side Caching Policies:
  • AI Plans Cache: 5-minute TTL per event stored in global EventContext.
  • Budget & Expenses Cache: 2-minute TTL, invalidated immediately upon recording an expense.
  • Task Timeline Cache: 90-second TTL with optimistic UI toggle updates.
  • Dashboard Analytics: Single consolidated endpoint (/api/dashboard/metrics) replacing multiple independent API calls.
  • Request Deduplication: Prevents duplicate in-flight API requests during rapid navigation.
